# Security policy

Driftless Web is a static, client-side application with no backend, accounts or server-side data.
The most relevant classes of issue are therefore cross-site scripting, anything that makes the app
contact an unapproved host or leak portfolio data, and flaws in file import (backup / CLI JSON).

Please report suspected vulnerabilities privately through GitHub's **"Report a vulnerability"**
(Security tab of this repository) rather than a public issue. Include steps to reproduce and the
affected version. Do not include real financial data.
